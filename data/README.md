# Dummy data directory for LoanHer prototype

This folder holds all the **fictional** fixture files used by the backend.
**Do not put any real personal or banking data here.**

## Data files

| File | Purpose | Status |
|------|---------|--------|
| `cac_records.json` | Fictional CAC business registrations (used by `services/cac.py`) | ✅ Created |
| `persona_kemi.json` | Template for the demo passport (scoring, ajo metrics, checklist) | ✅ Created |
| `passports_seed.json` | Complete seed loan passports for officer queue (`seed-ngozi`, `seed-halima`) | ✅ Created |
| `applications_seed.json` | Seed loan applications for the officer dashboard demo (`WB-1001`, `WB-1002`) | ✅ Created |
| `statement/kemi_statement.pdf` | 11-month synthetic bank statement (generated by `scripts/generate_statement.py`) | ⬜ To be generated |
